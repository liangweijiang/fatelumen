# 命理基础数据中心 V1

版本：`bazi-base-data-v1`

## 设计边界

- 五行、干支、藏干、十神映射和固定关系是确定性事实，以版本化代码保存，不进入业务数据库。
- 身强身弱等算法只能通过 `internal/bazi/basedata` 读取，禁止在业务模块复制映射表。
- 服务启动时校验五行关系、十天干、十二地支、藏干权重及关系成员引用；校验失败时拒绝启动。
- 管理端仅提供只读检查。规则调整必须新增版本，不能覆盖历史报告依赖的旧版本。

## 管理端接口

以下接口均位于 `/api/v1/admin`，必须使用 Admin Token：

- `GET /bazi-base/summary`
- `GET /bazi-base/elements`
- `GET /bazi-base/stems`
- `GET /bazi-base/branches`
- `GET /bazi-base/ten-gods`
- `GET /bazi-base/relations`
- `GET /bazi-base/strength-rules`

列表接口支持 `q`、`page`、`page_size`；关系接口额外支持 `type`。返回稳定代码、四语名称和基础数据版本。

管理页面：`/admin/bazi-base`。
