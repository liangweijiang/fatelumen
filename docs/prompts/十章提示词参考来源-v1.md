## 5. 编排与显示字典约定

- 章节输入区只代入当前计算档案、本章白名单所需的中文摘要，不追加完整事实 JSON。
- 内部事实编码由后端版本化显示字典 `bazi-display-dictionary-v1` 统一转换；原始编码仅保留在追溯数据中。
- 管理端运行时读取同一后端字典，前端内置词条仅作为登录与加载阶段的兼容兜底。
- 正式 Prompt 不携带事实哈希、locale、章节内部 key 等审计元数据。
- 每章直接在原“输出要求”后固定中文 JSON 协议：`章节 + 模块[{序号,名称,正文}]`，模块数量、名称和顺序不可调整。
