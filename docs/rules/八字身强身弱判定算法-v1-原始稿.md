# 八字身强身弱判定算法（完整版：含合冲刑害与从格）

## 1. 算法概述

本算法基于传统子平命理主流规则，采用**加权评分法**量化日主旺衰。核心思想：将八字各位置的五行力量按对日主的“生扶”与“克泄耗”进行分类，累加后比较比例，并经过合冲刑害的修正，最终判定身强、身弱、中和或从格。本版本**不包含喜用神推导**，聚焦旺衰判定。

## 3. 十神计算规则

### 3.1 十神定义

以日主天干为“我”，根据五行生克和阴阳异同：

| 关系 | 阴阳相同 | 阴阳不同 |
|------|----------|----------|
| 同我（比劫） | 比肩 | 劫财 |
| 我生（食伤） | 食神 | 伤官 |
| 我克（财）   | 偏财 | 正财 |
| 克我（官杀） | 七杀 | 正官 |
| 生我（印）   | 偏印 | 正印 |

### 3.2 十神归类

- **生扶类**：正印、偏印、比肩、劫财
- **克泄耗类**：正官、七杀、食神、伤官、正财、偏财

## 4. 核心计算流程

### 4.1 初始化

```python
support = 0.0      # 生扶总分
restraint = 0.0    # 克泄耗总分
```

### 4.2 月令旺衰基础分

取月支本气五行，查表2.3得基础分。  
若基础分为正：`support += 基础分`  
若基础分为负：`restraint += abs(基础分)`

### 4.3 天干力量统计

遍历年干、月干、时干（跳过日干）：
1. 查天干五行。
2. 计算十神。
3. 根据十神归类，将位置权重加入对应分数。

### 4.4 地支藏干力量统计

遍历年支、月支、日支、时支：
1. 取地支藏干列表。
2. 对于每个藏干：
   - 若为月支且藏干为本气（列表第一个），实际权重 = 位置权重 × 藏干权重 × 0.3
   - 否则，实际权重 = 位置权重 × 藏干权重
3. 计算十神，归类后累加。

### 4.5 合冲刑害修正（详见第5节）

应用天干五合、地支六合、三合、三会、相冲、相刑、相害的调整规则，修正 `support` 与 `restraint` 分数。

### 4.6 计算比例

```python
total = support + restraint
ratio = support / total if total > 0 else 0.5
```

### 4.7 根气判定

检查日主五行在地支藏干中的根气：
- **强根**：本气与日主同五行（权重≥0.6）
- **中根**：中气与日主同五行（权重≥0.3）
- **弱根**：余气与日主同五行（权重0.1）
- **无根**：所有藏干均无日主五行

有根指存在强根或中根；仅有弱根视为“微根”。

## 5. 合冲刑害完整实现规则

合冲刑害的修正采用**加分/减分制**，直接调整 `support` 或 `restraint`。规则中“加分”表示增加该五行的力量，并归入对应的生扶或克泄耗类别；“减分”表示削弱该五行的力量，从对应的生扶或克泄耗分数中扣除（若原分数不足则忽略）。

### 5.1 天干五合

条件：年干、月干、日干、时干中任意两干相合（日干也可参与，但日干本身不参与力量计算，合化会影响其他天干的五行属性）。

| 天干合 | 合化五行 | 加分 |
|--------|----------|------|
| 甲己   | 土       | +10  |
| 乙庚   | 金       | +10  |
| 丙辛   | 水       | +10  |
| 丁壬   | 木       | +10  |
| 戊癸   | 火       | +10  |

**合化条件**：合化五行在月令当令或得生助（月支五行生助合化五行），则合化成功；否则只合不化，双方天干原五行力量各减5（若该天干在计算中已计入对应分数）。

**调整方式**：
- 若合化成功：将合化五行对应的十神归类，加入 `support` 或 `restraint` 10分。
- 若合化不成功：从两个天干原本贡献的力量中各减去5分（分别从它们对应的生扶/克泄耗分数中扣除）。

**注意**：若参与合的天干是日主，则日主本身不贡献分数，但合化后可能改变日主五行属性？传统上日主不因合而化，故我们仅处理其他天干。

### 5.2 地支六合

条件：命局四支中出现六合组合。

| 六合 | 合化五行 | 加分 |
|------|----------|------|
| 子丑 | 土       | +8   |
| 寅亥 | 木       | +8   |
| 卯戌 | 火       | +8   |
| 辰酉 | 金       | +8   |
| 巳申 | 水       | +8   |
| 午未 | 土       | +8   |

**合化条件**：合化五行在月令当令或得生助，则合化成功；否则只合不化。

**调整方式**：
- 若合化成功：将合化五行归入对应十神类别，加8分。
- 若合化不成功：两个地支的藏干力量各减4分（从对应分数中扣除）。

**叠加**：若同一地支同时参与多个合，按一次处理（取最强的合）。

### 5.3 地支三合局

条件：四支中出现三合局的三个地支（如申子辰）。

| 三合局 | 合化五行 | 加分 |
|--------|----------|------|
| 申子辰 | 水       | +15  |
| 亥卯未 | 木       | +15  |
| 寅午戌 | 火       | +15  |
| 巳酉丑 | 金       | +15  |

**半合**：仅出现三合局中的两支（如申子、子辰、申辰），加7.5分。

**合化条件**：只要三支齐全即合化成功，无需月令支持；半合需月令生助才合化，否则不加分。

**调整方式**：将合化五行归入对应十神类别，加对应分数。

**注意**：若命局同时出现三合局和三会方，两者都成立，可叠加。

### 5.4 地支三会方

条件：四支中出现三个连续地支（如寅卯辰）。

| 三会方 | 会方五行 | 加分 |
|--------|----------|------|
| 寅卯辰 | 木       | +20  |
| 巳午未 | 火       | +20  |
| 申酉戌 | 金       | +20  |
| 亥子丑 | 水       | +20  |

**调整方式**：将五行归入对应十神类别，加20分。

**注意**：若三会方与三合局同时出现（如寅卯辰三会木局，又见亥卯未三合木局），可叠加计算。

### 5.5 地支相冲

条件：四支中出现相冲组合。

| 相冲 | 调整 |
|------|------|
| 子午 | 双方各减8 |
| 丑未 | 双方各减8 |
| 寅申 | 双方各减8 |
| 卯酉 | 双方各减8 |
| 辰戌 | 双方各减8 |
| 巳亥 | 双方各减8 |

**调整方式**：从被冲地支的每个藏干力量中减去相应数值（总减8，按藏干权重分配）。例如子藏癸水，直接减8；丑藏己癸辛，按权重0.6/0.3/0.1分配减分值：己减4.8，癸减2.4，辛减0.8。若该藏干对应生扶则减support，对应克泄耗则减restraint。

**特殊处理**：若被冲地支为月支，因其权重高，减分值可减半（即总减4）。

### 5.6 地支相刑

相刑包括三刑、自刑、无礼之刑等。规则：

| 类型 | 组合 | 调整 |
|------|------|------|
| 无礼之刑 | 子卯刑 | 双方各减4 |
| 恃势之刑 | 寅巳申三刑 | 三方各减6（若仅两支出现，各减3） |
| 无恩之刑 | 丑戌未三刑 | 三方各减6（若仅两支出现，各减3） |
| 自刑 | 辰辰、午午、酉酉、亥亥 | 自刑者减4 |

**调整方式**：与相冲类似，按藏干权重分配减分，从对应类别扣除。

### 5.7 地支相害

| 相害 | 调整 |
|------|------|
| 子未害 | 双方各减3 |
| 丑午害 | 双方各减3 |
| 寅巳害 | 双方各减3 |
| 卯辰害 | 双方各减3 |
| 申亥害 | 双方各减3 |
| 酉戌害 | 双方各减3 |

**调整方式**：与相冲类似，按藏干权重分配减分，从对应类别扣除。

### 5.8 合冲刑害的处理顺序与叠加

按照“先合后冲，先合后刑害”的顺序处理：

1. **合**：天干五合、地支六合、三合、三会，先计算加分。
2. **冲**：处理后，若地支被冲，且该地支参与了合，则合可能被冲散。规则：若合局中的地支被冲，则合局减力一半（如三合局被冲一支，加分减半；三会方同理；六合被冲则合化不成功，按原调整）。
3. **刑害**：最后处理，若刑害与合冲重叠，可累加减分。

**简化处理**：在实现中，可按顺序依次检测并应用调整，不做复杂的冲解合，仅做加减分。

## 6. 从格罗列与判定条件

从格分为**从强格**和**从弱格**两大类。从强格指日主极强，只能顺其势；从弱格指日主极弱，只能顺其势。

### 6.1 从强格

从强格又可分为**从印格**、**从比劫格**（有时统称从强）。判定条件：

1. **基本条件**：`ratio >= 0.85`（生扶比例极高）。
2. **日主有根**：至少中根（强根或中根）。
3. **月令为印比**：月令旺衰基础分为正（即月支五行生日主或与日主同五行）。
4. **全局克泄耗力量极弱**：克泄耗总分不超过总力量的15%，且单个克泄耗力量不超过8分。
5. **天干无官杀透出**：年干、月干、时干中无克制日主的十神（正官、七杀）。

满足以上所有条件可判定为从强。若不满足第4或第5条，则降级为普通身强。

**从印格与从比劫格的区别**：
- 从印格：生扶力量中以印星为主（印星力量 > 比劫力量）。
- 从比劫格：生扶力量中以比劫为主（比劫力量 > 印星力量）。
两者在旺衰判定上无实质区别，均按从强处理。

### 6.2 从弱格

从弱格又分为**从财格**、**从官杀格**、**从食伤格**、**从势格**。判定条件：

1. **基本条件**：`ratio <= 0.15`（生扶比例极低）。
2. **日主无根**：无强根、中根，仅有弱根或完全无根。
3. **月令为财官食伤**：月令旺衰基础分为负（即月支五行是日主所克、克日主或日主所生）。
4. **全局生扶力量极弱**：生扶总分不超过总力量的15%，且单个生扶力量不超过8分。
5. **天干无比劫印星透出**：年干、月干、时干中无帮扶日主的十神（比肩、劫财、正印、偏印）。

满足以上条件可判定为从弱。若第4或第5条不满足，则降级为普通身弱。

**从弱格细分**：
- **从财格**：克泄耗力量中以财星为主（财星力量最大）。
- **从官杀格**：克泄耗力量中以官杀为主（官杀力量最大）。
- **从食伤格**：克泄耗力量中以食伤为主（食伤力量最大）。
- **从势格**：财、官、食伤力量较为均衡，无突出五行，日主不得不从。

在旺衰判定时，均输出为“从弱”，如需细分可附加判断：比较财、官、食伤三类分数，取最大者命名。

### 6.3 假从格

若基本满足从格条件，但存在微弱的破格因素（如天干透出一点比劫，但被合化或克制；或地支有微根但被冲掉），可视为**假从**。传统上假从格仍按从格论，但运势起伏较大。本算法简化处理：若满足从格判定但存在以下情况之一，标记为“假从”：
- 天干透出比劫或印星，但被合化（如甲己合土，甲木被合去）。
- 地支有弱根，但被冲克（如日主为木，地支辰中乙木为弱根，但辰被戌冲）。

实现时可根据需要输出“假从强”或“假从弱”。

## 7. 判定规则总结

```text
if ratio >= 0.85 且 有根(强/中) 且 月令基础分为正 且 克泄耗总和 <15% 且 无官杀透出:
    结果 = 从强
elif ratio <= 0.15 且 无根 且 月令基础分为负 且 生扶总和 <15% 且 无比劫印星透出:
    结果 = 从弱
elif ratio >= 0.65:
    结果 = 身强
elif ratio <= 0.35:
    结果 = 身弱
else:
    结果 = 中和
```

def apply_combinations(bazi, support, restraint, day_gan):
    day_wx = TIAN_GAN_WUXING[day_gan]
    # 获取四柱干支
    year_gan, month_gan, day_gan_self, hour_gan = bazi['year_gan'], bazi['month_gan'], bazi['day_gan'], bazi['hour_gan']
    year_zhi, month_zhi, day_zhi, hour_zhi = bazi['year_zhi'], bazi['month_zhi'], bazi['day_zhi'], bazi['hour_zhi']
    ganzhi_list = [year_gan, month_gan, hour_gan]  # 不包括日干

    # 辅助函数：将五行转换为对应的十神类别并加减分
    def add_wuxing_score(wuxing, points):
        nonlocal support, restraint
        # 判断该五行对日主是生扶还是克泄耗
        # 用该五行与日主五行的关系简化判断，避免构造天干
        wx = TIAN_GAN_WUXING[day_gan]
        if wuxing == wx:  # 同我
            support += points
        elif (wuxing == '木' and wx == '火') or (wuxing == '火' and wx == '土') or \
             (wuxing == '土' and wx == '金') or (wuxing == '金' and wx == '水') or \
             (wuxing == '水' and wx == '木'):  # 生我
            support += points
        elif (wx == '木' and wuxing == '火') or (wx == '火' and wuxing == '土') or \
             (wx == '土' and wuxing == '金') or (wx == '金' and wuxing == '水') or \
             (wx == '水' and wuxing == '木'):  # 我生
            restraint += points
        elif (wuxing == '金' and wx == '木') or (wuxing == '水' and wx == '火') or \
             (wuxing == '木' and wx == '土') or (wuxing == '火' and wx == '金') or \
             (wuxing == '土' and wx == '水'):  # 克我
            restraint += points
        elif (wx == '金' and wuxing == '木') or (wx == '水' and wuxing == '火') or \
             (wx == '木' and wuxing == '土') or (wx == '火' and wuxing == '金') or \
             (wx == '土' and wuxing == '水'):  # 我克
            restraint += points

    # 辅助函数：从地支藏干中扣除力量
    def subtract_from_zhi(zhi, points):
        nonlocal support, restraint
        cang_list = DI_ZHI_CANG_GAN[zhi]
        total_weight = sum(w for _, w in cang_list)
        for gan, w in cang_list:
            deduct = points * (w / total_weight)
            shishen = get_shishen(day_gan, gan)
            if shishen in SUPPORT_SHISHEN:
                support -= deduct
            else:
                restraint -= deduct

    # 天干五合
    gan_he_map = {('甲','己'):'土', ('乙','庚'):'金', ('丙','辛'):'水', ('丁','壬'):'木', ('戊','癸'):'火'}
    for g1, g2 in [('甲','己'),('乙','庚'),('丙','辛'),('丁','壬'),('戊','癸')]:
        if (g1 in [year_gan, month_gan, hour_gan] and g2 in [year_gan, month_gan, hour_gan]):
            # 合化成功条件：月支五行生助合化五行
            he_wuxing = gan_he_map[(g1,g2)]
            month_wuxing = TIAN_GAN_WUXING[DI_ZHI_CANG_GAN[month_zhi][0][0]]
            # 月支五行生合化五行？
            sheng_relation = (month_wuxing == '木' and he_wuxing == '火') or \
                             (month_wuxing == '火' and he_wuxing == '土') or \
                             (month_wuxing == '土' and he_wuxing == '金') or \
                             (month_wuxing == '金' and he_wuxing == '水') or \
                             (month_wuxing == '水' and he_wuxing == '木')
            if sheng_relation or month_wuxing == he_wuxing:
                add_wuxing_score(he_wuxing, 10)
            else:
                # 不合化，双方天干原力量各减5
                for gan in [g1, g2]:
                    if gan in [year_gan, month_gan, hour_gan]:
                        pos = 'year_gan' if gan == year_gan else ('month_gan' if gan == month_gan else 'hour_gan')
                        shishen = get_shishen(day_gan, gan)
                        if shishen in SUPPORT_SHISHEN:
                            support -= 5
                        else:
                            restraint -= 5

    # 地支六合
    zhi_he_map = {('子','丑'):'土', ('寅','亥'):'木', ('卯','戌'):'火', ('辰','酉'):'金', ('巳','申'):'水', ('午','未'):'土'}
    all_zhi = [year_zhi, month_zhi, day_zhi, hour_zhi]
    for (z1, z2), he_wx in zhi_he_map.items():
        if z1 in all_zhi and z2 in all_zhi:
            month_wx = TIAN_GAN_WUXING[DI_ZHI_CANG_GAN[month_zhi][0][0]]
            sheng_relation = (month_wx == '木' and he_wx == '火') or \
                             (month_wx == '火' and he_wx == '土') or \
                             (month_wx == '土' and he_wx == '金') or \
                             (month_wx == '金' and he_wx == '水') or \
                             (month_wx == '水' and he_wx == '木')
            if sheng_relation or month_wx == he_wx:
                add_wuxing_score(he_wx, 8)
            else:
                subtract_from_zhi(z1, 4)
                subtract_from_zhi(z2, 4)

    # 地支三合局
    sanhe_groups = [
        ({'申','子','辰'}, '水', 15),
        ({'亥','卯','未'}, '木', 15),
        ({'寅','午','戌'}, '火', 15),
        ({'巳','酉','丑'}, '金', 15)
    ]
    for group, wx, points in sanhe_groups:
        present = [z for z in group if z in all_zhi]
        if len(present) == 3:
            add_wuxing_score(wx, points)
        elif len(present) == 2:
            # 半合，需月令生助
            month_wx = TIAN_GAN_WUXING[DI_ZHI_CANG_GAN[month_zhi][0][0]]
            sheng_relation = (month_wx == '木' and wx == '火') or \
                             (month_wx == '火' and wx == '土') or \
                             (month_wx == '土' and wx == '金') or \
                             (month_wx == '金' and wx == '水') or \
                             (month_wx == '水' and wx == '木')
            if sheng_relation or month_wx == wx:
                add_wuxing_score(wx, points/2)

    # 地支三会方
    sanhui_groups = [
        ({'寅','卯','辰'}, '木', 20),
        ({'巳','午','未'}, '火', 20),
        ({'申','酉','戌'}, '金', 20),
        ({'亥','子','丑'}, '水', 20)
    ]
    for group, wx, points in sanhui_groups:
        if all(z in all_zhi for z in group):
            add_wuxing_score(wx, points)

    # 地支相冲
    chong_pairs = [('子','午'),('丑','未'),('寅','申'),('卯','酉'),('辰','戌'),('巳','亥')]
    for z1, z2 in chong_pairs:
        if z1 in all_zhi and z2 in all_zhi:
            # 月支减半
            if z1 == month_zhi or z2 == month_zhi:
                subtract_from_zhi(z1, 4)
                subtract_from_zhi(z2, 4)
            else:
                subtract_from_zhi(z1, 8)
                subtract_from_zhi(z2, 8)

    # 地支相刑
    xing_pairs = [('子','卯')]  # 无礼之刑
    for z1, z2 in xing_pairs:
        if z1 in all_zhi and z2 in all_zhi:
            subtract_from_zhi(z1, 4)
            subtract_from_zhi(z2, 4)
    # 恃势之刑：寅巳申
    for z1, z2 in [('寅','巳'),('巳','申'),('寅','申')]:
        if z1 in all_zhi and z2 in all_zhi:
            subtract_from_zhi(z1, 3)
            subtract_from_zhi(z2, 3)
    # 无恩之刑：丑戌未
    for z1, z2 in [('丑','戌'),('戌','未'),('丑','未')]:
        if z1 in all_zhi and z2 in all_zhi:
            subtract_from_zhi(z1, 3)
            subtract_from_zhi(z2, 3)
    # 自刑：辰辰、午午、酉酉、亥亥
    for z in ['辰','午','酉','亥']:
        if all_zhi.count(z) >= 2:
            subtract_from_zhi(z, 4)

    # 地支相害
    hai_pairs = [('子','未'),('丑','午'),('寅','巳'),('卯','辰'),('申','亥'),('酉','戌')]
    for z1, z2 in hai_pairs:
        if z1 in all_zhi and z2 in all_zhi:
            subtract_from_zhi(z1, 3)
            subtract_from_zhi(z2, 3)

    return support, restraint

# ================== 主分析函数 ==================
def analyze_bazi(bazi):
    day_gan = bazi['day_gan']
    day_wx = TIAN_GAN_WUXING[day_gan]
    support = 0.0
    restraint = 0.0

    # 1. 月令旺衰
    month_zhi = bazi['month_zhi']
    month_main_gan = DI_ZHI_CANG_GAN[month_zhi][0][0]
    month_main_wx = TIAN_GAN_WUXING[month_main_gan]
    month_score = MONTH_SCORE[month_main_wx][day_wx]
    if month_score > 0:
        support += month_score
    else:
        restraint += abs(month_score)

    # 2. 天干
    for pos in ['year_gan','month_gan','hour_gan']:
        gan = bazi[pos]
        if gan == day_gan:
            continue
        shishen = get_shishen(day_gan, gan)
        w = POSITION_WEIGHT[pos]
        if shishen in SUPPORT_SHISHEN:
            support += w
        else:
            restraint += w

    # 3. 地支藏干
    for pos in ['year_zhi','month_zhi','day_zhi','hour_zhi']:
        zhi = bazi[pos]
        base_w = POSITION_WEIGHT[pos]
        cang_list = DI_ZHI_CANG_GAN[zhi]
        for i, (gan, inner_w) in enumerate(cang_list):
            if pos == 'month_zhi' and i == 0:  # 月支本气降权
                eff_w = base_w * inner_w * 0.3
            else:
                eff_w = base_w * inner_w
            shishen = get_shishen(day_gan, gan)
            if shishen in SUPPORT_SHISHEN:
                support += eff_w
            else:
                restraint += eff_w

    # 4. 合冲刑害修正
    support, restraint = apply_combinations(bazi, support, restraint, day_gan)

    # 5. 比例
    total = support + restraint
    ratio = support / total if total > 0 else 0.5

    # 6. 根气
    root = check_root(bazi, day_wx)

    # 7. 从格判定
    # 检查天干是否有官杀透出
    has_guan_sha = False
    for gan in [bazi['year_gan'], bazi['month_gan'], bazi['hour_gan']]:
        shishen = get_shishen(day_gan, gan)
        if shishen in ['正官','七杀']:
            has_guan_sha = True
            break
    # 检查天干是否有比劫印星透出
    has_bijie_yin = False
    for gan in [bazi['year_gan'], bazi['month_gan'], bazi['hour_gan']]:
        shishen = get_shishen(day_gan, gan)
        if shishen in SUPPORT_SHISHEN:
            has_bijie_yin = True
            break

    # 计算生扶/克泄耗占比
    support_ratio = ratio
    restraint_ratio = 1 - ratio

    if ratio >= 0.85 and root in ['strong','medium'] and month_score > 0 and restraint_ratio <= 0.15 and not has_guan_sha:
        result = '从强'
    elif ratio <= 0.15 and root in ['weak','none'] and month_score < 0 and support_ratio <= 0.15 and not has_bijie_yin:
        result = '从弱'
    elif ratio >= 0.65:
        result = '身强'
    elif ratio <= 0.35:
        result = '身弱'
    else:
        result = '中和'

    return result, ratio, support, restraint

# ================== 使用示例 ==================
if __name__ == '__main__':
    bazi = {
        'year_gan':'甲', 'year_zhi':'子',
        'month_gan':'丙', 'month_zhi':'寅',

## 9. 注意事项

1. **合冲刑害的顺序**：代码中按照“天干五合 → 地支六合 → 三合 → 三会 → 相冲 → 相刑 → 相害”的顺序执行，可能产生叠加效应，但未实现“冲解合”等复杂逻辑。实际应用时可进一步优化。
2. **从格判定条件**：代码中使用了 `restraint_ratio <= 0.15` 和 `support_ratio <= 0.15` 作为全局力量占比的辅助判断，与 `ratio` 阈值配合使用。用户可根据需要调整阈值。
3. **假从格**：代码未单独输出假从，若需可增加额外标志位。
4. **权重和阈值**：所有数值（如位置权重、加减分、阈值）均为经验值，可通过大量案例验证调整。
5. **合化条件简化**：月令生助合化五行的判断用了五行相生关系，实际可能还需考虑月令本身旺衰，可进一步细化。
