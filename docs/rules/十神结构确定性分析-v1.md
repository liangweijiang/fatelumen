# 十神结构确定性分析 V1

## 1. 边界

- 规则版本：`ten-god-rule-v1`。
- 输入只来自已经完成的四柱、统一命理基础数据和身强身弱分析证据。
- 本模块不重新识别干支合冲刑害，不计算喜用神，也不生成自然语言结论。
- 十神名称与映射来自 `bazi-base-data-v1`，固定事实不存业务数据库。

## 2. 计算流程

1. 以日干为参照，将年干、月干、时干和四支藏干映射为十神；日干自身不计入十神力量。
2. 显干使用基础数据中的柱位权重；藏干使用柱位权重乘本气、中气、余气比例。月支本气沿用身强身弱引擎已经采用的月令系数。
3. 汇总十个十神的原始力量，记录是否透干、是否在地支有根，并按力量稳定排序。
4. 聚合为五类：`peer`（比劫）、`resource`（印星）、`output`（食伤）、`wealth`（财星）、`officer`（官杀）。
5. 关系调整只消费 `StrengthAnalysis.Relations`。有明确转化五行和分值的关系按该五行相对日主所属的五类计入；没有转化五行或分值为零的关系仅保留在原关系事实中，不臆造十神调整。
6. 输出主导十神（前两名）、次要十神（第 3—5 名）、缺失十神、透干十神、有根十神、集中度、十神排名和五类排名。

## 3. 分值解释

- `raw_score`：位置权重和藏干比例得到的原始力量。
- `relation_adjustment`：复用身强身弱关系证据得到的五类调整值。
- `effective_score`：五类层面为 `max(0, raw_score + relation_adjustment)`。
- 单个十神无法从一个转化五行可靠区分阴阳时，不把类别调整强行分摊到正神或偏神，因此十神层面的 `effective_score` 暂与 `raw_score` 相同。
- `concentration`：原始力量最高的十神占全部十神原始力量的比例。

## 4. 可追溯输出

- 命盘：`ChartData.ten_god_analysis` 保存完整分析结果和证据。
- 报告事实：`InterpretationFacts.ten_god_structure` 保存摘要、十神逐项和五类逐项事实。
- 版本：`InterpretationFactVersions.ten_god_rule_version` 固定本次规则版本。
- 哈希：十神结果和版本进入 `facts_hash`；Prompt 版本变化仍不影响确定性事实哈希。

## 5. 后续扩展

喜用神必须使用用户确认的独立规则和独立版本。该模块可以读取十神结构，但不得覆盖或修改本模块的历史快照。
