# 五行力量引擎 V2-A 实现规范

## 1. 来源与版本

本实现依据 `八字五行力量身强身弱与喜用神算法-v2.0-原始稿.md`。V2-A 历史规则版本固定为 `bazi-power-v1.0`；V2-B 已升级为 `bazi-power-v2.0`。原始稿保持原样，本文件只记录 V2-A 的实现边界。

## 2. 已实现流水线

1. 四柱天干和地支藏干展开。
2. 八位置权重：年干 0.85、月干 1.15、日干 1.00、时干 0.95、年支 1.00、月支 1.80、日支 1.35、时支 1.05。
3. 单藏、双藏和三藏分别采用原始规范的比例，避免旧基础数据 0.6/0.3/0.1 与 V2 口径混用。
4. 十二月支五行矩阵。
5. 根据上一节与下一节的时间计算 `SeasonProgress`，对当前月支和下一月支系数连续插值。
6. 透干奖励，月令与月令本气采用更高倍率，且上限不超过 1.20。
7. 日主根气单独计算，不重复加入五行总量。
8. 生扶采用能量转移模型；克制采用攻击方力量、接触系数和强弱比系数；固定两轮迭代，第二轮系数减半。
9. 输出原始力量、季节力量、有效力量和归一化百分比，并保留逐项贡献、根气、每轮生克和规则追踪。

## 3. 当前明确未完成的边界

合化置信度、三合/半合/三会、六冲留存率、刑害破可用性修正已在 V2-B 的结构交互引擎中接入。只有显式调用历史 `bazi-power-v1.0` 规则时仍带有 `structural_transformations_pending_v2_b` 警告。

身强身弱 V1 和十神原始力量 V1 继续保留，以兼容历史快照。当前新命盘同时保存身强身弱 V2 与有效十神 V2；两者消费 V2-B 的有效五行力量。

## 4. 快照与哈希

- `ChartData.element_power` 保存完整计算过程。
- `InterpretationFacts.element_strength` 保存五行百分比及贡献证据。
- `InterpretationFactVersions.element_power_rule_version` 保存规则版本。
- 规则版本与全部计算结果进入 `facts_hash`。

## 5. 喜用神边界

喜用神是后续独立模块。它只能消费完成结构交互、身强弱 V2、格局、调候、病药和通关后的确定性结果，不能根据当前 V2-A 五行百分比直接查表生成。
