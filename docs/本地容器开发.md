# 本地容器开发

## 推荐：统一开发启动脚本

本机开发前先启动 v2rayN，然后在仓库根目录执行：

```powershell
.\start-dev.ps1 -Restart
```

脚本会统一完成以下工作：

- 启动 MySQL 与 Redis 容器；
- 固定后端回调地址 `http://localhost:3000`；
- 为 Go 后端注入本地 Google 访问代理，默认使用 `http://127.0.0.1:10808`；
- 从当前源码重新编译后端；
- 使用 Turbopack 启动前端；
- 验证前端和后端均可访问。

如果 v2rayN 的 HTTP 代理端口发生变化，可显式覆盖：

```powershell
.\start-dev.ps1 -Restart -ProxyUrl "http://127.0.0.1:你的端口"
```

这些代理变量仅注入本次本地开发进程，不写入 `.env.local`，也不影响线上部署。

在仓库根目录执行：

```powershell
docker compose up --build
```

启动后：

- 用户前端：http://localhost:3000
- 后端健康检查：http://localhost:8080/health
- MySQL：localhost:3307（`fatelumen` / `fatelumen123`）
- Redis：localhost:6380

开发 Compose 默认关闭外部支付，并使用 DeepSeek 占位 Key，因此不会自动产生支付或外部模型调用。Google 登录由可选的 `backend/.env.local` 启用；该文件被 Git 忽略，严禁提交真实密钥。

## 使用 Google 登录测试

1. 复制 `backend/.env.local.example` 为 `backend/.env.local`。
2. 在 Google Cloud 创建 Web application 类型 OAuth 2.0 Client，并登记授权重定向 URI：

   ```text
   http://localhost:8080/api/v1/auth/google/callback
   ```

3. 仅在 `backend/.env.local` 填入 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`JWT_SECRET` 与 `ADMIN_JWT_SECRET`。后两项应为分别生成的随机长字符串；同时设置 `JWT_EXPIRE_HOURS=168`（7 天）。不要把任何一项写进 Compose、文档或 Git。
4. 执行 `docker compose up -d --force-recreate backend`，再访问 http://localhost:3000/login。

Google 授权完成后，后端会重定向到前端 `/login/callback`。浏览器以一次性、两分钟有效的兑换码取得会话；JWT 不会出现在 URL 或回调页面 JSON 中。

常用命令：

```powershell
docker compose up --build
docker compose down
docker compose logs -f backend
docker compose ps
```

后端镜像内置 Chromium 与 Noto CJK 字体，用于 PDF 开发验证。持久化的 MySQL、Redis 和本地文件存储均使用命名卷；执行 `docker compose down` 不会删除它们。
